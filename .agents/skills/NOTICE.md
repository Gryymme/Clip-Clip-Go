# Installed skill sources

These skills were installed for Codex at project scope using `skills` 1.9.0. The source commits and content hashes are recorded in the project-root `skills-lock.json`. Each skill is installed once in `.agents/skills/<name>/`, the supported Codex project discovery location; no other agent-specific directories were configured.

- The 20 skills sourced from `emilkowalski/skills` are covered by the upstream MIT license preserved in `LICENSE.emilkowalski.txt` beside this notice.
- `stageshow`, sourced from `benjitaylor/skills`, retains its own `LICENSE`, `NOTICE.md`, third-party notices, references, examples, assets, kit, and scripts inside its directory. Its package manifests are bundled resources; its playground dependencies have not been installed into the skill or application.

Read the project-root `DESIGN.md` and follow the routing in `AGENTS.md` before using these skills. Explicit project requirements take precedence over external skill guidance. Installation does not authorize running playgrounds, adding libraries, or changing application behavior.
