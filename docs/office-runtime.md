# Document scope decision

LibreOffice integration and the proposed optional Office installer component are permanently cancelled by product decision. Microsoft Office and OpenDocument formats are unsupported. The application retains audio/video, images and native text conversion, and its document scope is TXT, Markdown, HTML and PDF.

The abandoned runtime, archives, copied fonts/CRTs, resource copies, preparation hooks, notices, AppContainer experiments and large diagnostics were removed from the project. Prior experiment cleanup succeeded; this removal creates no profiles and changes no permissions outside the project. No system installation, shared fonts, unrelated caches or user documents are touched.

This short note is intentionally historical. There is no remaining Office runtime deployment plan. See README.md for implemented conversion routes and limitations.
