# Packaging scope

Audio/video, images and supported text/PDF conversion are included by default. Required runtime libraries, redistributable fonts and notices accompany the app; users do not install conversion tools, configure paths or download engines at first launch. Portable copies must retain the complete resource tree.

LibreOffice and optional Office installation are cancelled. Microsoft Office and OpenDocument formats are unsupported. There is no optional Office component, delivery, maintenance or uninstall requirement.

Installer packaging is separate from native debug-build verification. Retained FFmpeg corresponding-source/redistribution obligations remain documented under third-party/ffmpeg; the application license has not changed.
